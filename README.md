# Final Assignment
## Narzędzia programistyczne w Pythonie wspierające analizę danych
### Wojciech Socha

The following project calculates basic statistics of a given work or/and
a given dictionary including listing top n most frequent words.
Additionally, it can also present words in given works 
that are not in a given dictionary.

I've also constructed my own measure of how similar are two given works.
It is based on top n most frequent words in each work. You can also plot
how one work is similar to the other.
